## 3. Oracles and independence

- Production kernel and oracle never share code: trimesh, numpy-stl, CGAL (CI container), PyMeshLab (CI container), brute-force O(n²) reference implementations and rational arithmetic.
- Oracle disagreement is triaged, never auto-accepted; the analytic truth wins over any library.
- Oracle images are not shipped (ADR-011).

## 4. Regression and determinism

- Golden hashes for T9 designs per kernel image (FN-OPS-04); any change requires a recorded justification and op_version/kernel_version bump.
- 100-run determinism per design on CI host; cross-host run on a second host before pilot (BM-03).
- Library upgrade = full regression on stored designs (R-29).

## 5. Numerical stability policy

- Tolerances from DEC-025 only (e = 0.011 mm, perimeter 0.032 mm, file fidelity 1e-4 mm); no ad-hoc epsilons in tests.
- Exact predicates tested against rational arithmetic on T13.
- Metamorphic tests use exact transforms (axis permutations, power-of-two scaling) so expected equality is bitwise.
- Summation order fixed; tests assert bitwise equality where the specification promises it (e.g. vertices outside a zone).

## 8. Traceability

Each function specification lists UT-FN-… (proposed) and catalogue TC-… IDs with suites; each ALG row lists its tests. New fixture sets T13–T15 and proposed UT IDs must be added to the test catalogue (v0.4) before baseline.
